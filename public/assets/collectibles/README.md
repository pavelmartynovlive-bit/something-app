# PNG корма и Lipton

Подключены оригинальные PNG из «Архив 3.zip», без перерисовки:

- `food.png`: обычный пакет, исходник `09_37_07 PM.png`.
- `lipton.png`: бутылка с тёмной обводкой, исходник `09_37_15 PM.png`.

Все пять вариантов сохранены в `art-assets/collectibles/`. Там же находится
`manifest.json` с исходными именами и SHA-256. Варианты со свечением и мягкой
обводкой не вводят дополнительные типы предметов и не загружаются в игру.

Выбор исходников задан в `src/collectible-sources.json`. Значение `null`
возвращает прежнюю программную графику для соответствующего предмета.

Нужны изображения с прозрачным фоном. Альфа-границы определяются автоматически;
пропорции сохраняются. Подготовленные рамки: корм 36×40, Lipton 42×52.
Зоны подбора, координаты, награды и игровая логика остаются прежними.
Исходники автоматически входят в офлайн-кеш при сборке.

Проверка: `npm run build` и `npm run test:collectible-visual` при работающем
`npm run dev`. Тест загружает реальные исходники и сравнивает зоны подбора,
координаты персонажа, энергию, корм, Lipton, падения и усиления прыжка
на каждом кадре полного повтора с программной графикой и с PNG.

Проверка офлайн-версии: после сборки запустить `npm run preview` и
`npm run test:collectible:production`. Она проверяет кеш и SHA-256 обоих PNG
после перезагрузки страницы с отключённой сетью.
