# Contextual Tanya animation source

Additional20-frame sheet generated against the approved basic animation sheet.
Right-facing loose-hair Tanya, pink hoodie/olive pants/orange mittens and boots.
No bench/enemy prop is embedded in the PNG. No existing basic frame was redrawn.

Row-major: bench-sit2, bench-idle4, bench-stand2, pit-fall4,
hit-granny3, hit-scooter5.1536×1024 RGBA,4columns×5rows.
Exact alpha-component rectangles are in tanya-context-atlas.json.
Production source PNG is a byte-identical copy, with per-frame foot/seat
registration metadata in public/assets/characters/tanya/animations.

See docs/tanya/contextual-integration.md for FPS, anchors, state priority,
physics behavior, validation and current manual phone review status.
