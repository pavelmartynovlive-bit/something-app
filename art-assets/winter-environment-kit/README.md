# Winter Moscow — modular environment kit

12 отдельных PNG, созданных GPT Image по зимнему московскому референсу.
Это набор независимых объектов, не цельная сцена и не новый уровень.

Откройте `preview.html`: переключатель светлой/тёмной подложки показывает
реальную прозрачность и читаемость. PNG можно скачать из каждой карточки.
Все файлы RGBA, 1024–2172 px по длинной/горизонтальной стороне;
точные размеры, SHA-256, содержательные границы и масштабы — в `manifest.json`.
Исходные пиксели сохранены без ресайза, вырезания или деформации.

## Масштаб и привязка

Общий условный масштаб набора: персонаж высотой 96 art px. Это не изменение
текущей физики игры. Для фактической высоты персонажа H используйте:

```
scale = manifest.assets[i].uniformScale * H / 96
sprite.setScale(scale) // одинаковый масштаб по обеим осям
sprite.setOrigin(...manifest.assets[i].bottomCenterOrigin)
```

`referenceContentHeight` вычислена из реальных пропорций, а не из запрошенного
у генератора размера. PNG имеют разный прозрачный отступ: не выравнивайте их
по размеру холста и не задавайте одинаковые displayWidth/displayHeight.
`bottomCenterOrigin` выравнивает нижний центр содержательной части, исключая
слабую периферийную альфу; снежную поверхность при интеграции выравнивайте
отдельно с существующей геометрией. Каталог показывает все объекты в одном
условном масштабе с нижним пунктирным ориентиром.

## Сборка модулей и коллизии

- Земля, скат, уступ и ступени используют одну снежно-бетонную палитру;
  платформы используют тот же материал и более короткий силуэт.
- Земля не заявлена математически бесшовным тайлом: края снежной шапки и
  текстура не идентичны. Для длинной поверхности используйте перекрытие
  стыков/кромок или последующую подготовку специальных бесшовных вариаций.
  Перила соединяются по стойкам с небольшим перекрытием общей стойки.
- `contentBoundsAlpha128` — [left, top, right, bottom) при alpha >=128,
  метаданные для масштабирования, НЕ collision mask. Снег и сосульки имеют
  декоративные края; границы коллизий нужно согласовать с поверхностями
  при интеграции. Не создавайте прямоугольную физику по всему PNG-холсту.
- Декорации не получают коллизии автоматически. Изображение лавочки само по
  себе не добавляет новую точку восстановления, жижа — новую механику урона.
- Набор ещё не подключён к сцене. Геймплей, энергия, фон, уровень и физика
  остаются без изменений. Не добавлен в public: не увеличивает текущий
  офлайн-кеш игры на 14 МБ до решения об интеграции.

## Проверено

12/12 PNG декодируются и содержат настоящую прозрачность (не шахматный фон).
Каждый файл содержит один объект. Просмотр каталога на светлой и тёмной
подложке, включая мобильный размер. Физическое совмещение коллизий и игровой
playtest потребуются при подключении; в этой задаче игровой код не менялся.
