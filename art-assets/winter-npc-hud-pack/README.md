# Персонажи и HUD зимнего двора

Восемь отдельных PNG с альфа-каналом, подготовленных по стилю Тани.

- `scooter-rider.png` — мальчик-курьер на зимнем самокате, направление вправо.
- `grandma-stroller.png` — бабушка с детской коляской, направление вправо.
- `pigeon-standing.png` — голубь стоит.
- `pigeon-walking.png` — голубь шагает.
- `pigeon-startled.png` — испуганный голубь раскрывает крылья на земле.
- `pigeon-takeoff.png` — голубь взлетает.
- `hud-normal.png` — два блока «Энергия» / «Корм», пример 41 / 28.
- `hud-low-energy.png` — те же блоки, низкая энергия 9 / 28.

Четыре позы голубя имеют одинаковые размеры холста. Два состояния HUD
также имеют одинаковые размеры холста. В `manifest.json` записаны размеры,
границы содержимого при alpha >= 128 и SHA-256 каждого файла.

Подключение: `src/npc-visual.ts` и `src/game-hud.ts`. Публичные исходники
находятся в `public/assets/npcs/` и `public/assets/hud/` и входят в офлайн-кеш.

NPC отображаются поверх прежних невидимых физических объектов. Размеры,
скорости, траектории и зоны урона сохранены. Перед первым кадром исходники
нормализуются в небольшие 256×256 текстуры, крупные исходные текстуры удаляются
из менеджера; повторные сцены используют готовые кадры.

Голуби чередуют стояние и шаг, при вспугивании раскрывают крылья, затем
используют кадры взлёта. Эти переключения не двигают физическую стаю.

Числа в PNG HUD — визуальный пример. В игре используются рамки и иконки
из PNG, а текущие значения и заполнение полосы отрисовываются отдельно.
Верхняя панель содержит только энергию и корм; установка доступна на экране
результата. Семантические значения HUD доступны программам чтения с экрана.

Проверки: `npm run test:npc-hud`, `npm run test:mobile`, `npm run test:finish`,
`npm run test:collectible-visual`. После сборки и запуска `npm run preview` —
`npm run test:collectible:production` для проверки всех десяти PNG и офлайн-запуска.
