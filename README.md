# Таня и голодный кот

Одна мобильная сцена auto-runner на Phaser 3 + TypeScript + Vite, без backend, внешнего арта и сохранений. Таня бежит сама; игрок управляет только прыжками. Шесть вручную заданных сцен, около 42 секунд на чистом маршруте при ориентире около 45 секунд. Портретная камера сохраняет постоянный масштаб. Дизайн задают `GAME_DESIGN.md` и `LEVEL_REFERENCES.md`: основа игры — меняющая высоту земля, верхние маршруты — короткие бонусы.

Нужен Node.js 22.12+ (или 20.19+).

```sh
npm ci
npm run dev
```

Открой адрес Vite. Для телефона в одной сети используй сетевой адрес компьютера и порт 5173. Играй вертикально.

```sh
npm run build
npm run preview
```

Production-файлы — в `dist/`. Размещай **всю папку** на статическом HTTPS-хостинге. Manifest, PNG-иконки и service worker включены в сборку. Относительные пути поддерживают размещение в подпапке, например на GitHub Pages.

## Установка на телефон

1. Опубликуй `dist/` и открой HTTPS-ссылку на телефоне. Адрес компьютера вида `http://192.168…` подходит для разработки, но не для полноценного PWA с офлайн-режимом.
2. Android: открой в Chrome и нажми «Установить» в игре, либо меню ⋮ → «Установить приложение» / «Добавить на главный экран».
3. iPhone: открой в Safari → «Поделиться» → «На экран Домой» → «Добавить». Системное окно установки на iOS нельзя открыть программно: кнопка игры показывает эти шаги.
4. Запускай с иконки. Играй вертикально; iOS может потребовать повернуть телефон вручную.

Для первой загрузки нужен интернет. В окне «Установить» дождись сообщения «Игра сохранена», затем можно проверить запуск в авиарежиме. Сохранения прогресса по-прежнему нет: каждый новый запуск начинает сцену заново. При новой публикации закрой все окна установленной игры и открой снова, чтобы применить обновление; текущий забег не перезагружается автоматически.

Варианты публикации:

| Вариант | Как разместить |
| --- | --- |
| Netlify — проще всего для первой проверки | Собери `npm run build`, загрузи папку `dist` через ручной deploy в Netlify. Получишь HTTPS-ссылку. |
| Vercel — автоматические обновления из GitHub | Подключи репозиторий, build command `npm run build`, output directory `dist`. |
| GitHub Pages — всё рядом с репозиторием | Публикуй содержимое `dist` через GitHub Actions; в настройках Pages выбери источник GitHub Actions. |

Сборка создаёт `dist/sw.js` со списком всех файлов и версией кеша. В `npm run dev` service worker не включается. Для локальной проверки PWA используй `npm run build` и `npm run preview` на localhost; для телефона нужна HTTPS-ссылка.

### GitHub Pages для этого репозитория

Workflow `.github/workflows/pages.yml` собирает игру при каждом push в `main` и публикует `dist/` через GitHub Actions.

1. В репозитории открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. Открой **Actions → Publish game to GitHub Pages → Run workflow**, выбери `main` и запусти. Последующие изменения в `main` публикуются автоматически.
3. После успешного job `deploy` ссылка на сайт будет в **Settings → Pages** и в deployment `github-pages`.

Workflow сначала проверяет, включён ли Pages и выбран ли источник GitHub Actions. Ошибка **Verify GitHub Pages is enabled** означает, что сайт недоступен токену workflow: проверь включение Pages и ограничения тарифа для приватных репозиториев. Ошибка **Verify Pages uses GitHub Actions** означает, что выбран другой источник публикации. После исправления настроек перезапусти workflow. Автоматическое включение Pages требует административного токена; он не добавляется в проект.

Ожидаемый адрес для этого репозитория: `https://pavelmartynovlive-bit.github.io/something-app/`. Он станет доступен только после успешной публикации. Если Pages недоступен для приватного репозитория на текущем тарифе, GitHub покажет ограничение в Settings → Pages; не меняй видимость репозитория без отдельного решения.

## Управление и механика

- Таня бежит вправо: 330px/s, при нуле энергии — 190px/s. Тап по игровой области, Space или ↑ вызывает прыжок. Coyote time — 130мс, buffer — 150мс.
- Энергия расходуется со скоростью 2/с; обычный прыжок не снимает отдельную энергию. Ящик или бабка снимают 15, самокат — 12 и замедляет на 650мс, птицы — 6. Общая защита от повторного удара — 1,4с.
- Lipton мгновенно даёт +22. Простое бездействие энергию не восстанавливает.
- Одна лавочка в секции «Карман отдыха»: при энергии ниже 65 касание отмеченной середины сиденья включает отдых на 2,5с, +22 энергии/с. Можно перепрыгнуть её, включая состояние энергии 0. После отдыха бег продолжается автоматически.
- Усталость уменьшает прыжок, но не убивает Таню. Уже начатая дуга сохраняет скорость до посадки, чтобы истощение посреди прыжка не меняло её неожиданно.
- Модель корма B: **100** для накормленного кота, **132** для кошачьего пира. HUD: «Корм: X», «Котику нужно: 100». Проверенные бюджеты: земля 126, обычный маршрут 128, коллекционный 137. Цель достигается в последней четверти чистого забега, бонус требует дополнительного исполнения.
- Земля — сплошные улицы, чаша, эстакада и заполненные террасы. Два коротких разрыва имеют страховочное дно на 24px ниже; промах не перезапускает уровень. Под террасами нет прохода.
- Единственный навес — в третьей сцене. Вход, приземление и прыжок с края дают 2,23с бонусного ответвления. Верхняя грань и стрелки показывают одностороннее приземление; фоновые опоры не блокируют проход.
- Самокат подъезжает по нижней улице к видимому торцу эстакады и упирается в него обычной физикой. Прыжок с края проходит на обеих скоростях. Камера не отдаляется; полностью видимый самокат читается за 0,57с до проверенного прыжка (1,22с при усталости).
- Промах верхнего маршрута возвращает на землю без перезапуска. Повторный забег сбрасывает энергию, предметы и счётчики.

## Шесть сцен

| Сцена | Примерное время | Ритм |
| --- | ---: | --- |
| Две кромки | 5с | Разрыв → посадка → низкий уступ → короткий сход |
| Птичья чаша | 7с | Спуск → отложенный прыжок над птицами → выход из чаши |
| Единственный козырёк | 6с | Общая бабушка → выбор → короткий бонус с края / проход снизу |
| Эстакада и встречный | 7с | Подъём → увидеть встречного → поздний прыжок на нижнюю улицу |
| Карман отдыха | 4с | Спуск → Lipton на прыжке ИЛИ лавочка → короткая передышка |
| Горка к коту | 12с | Две заполненные террасы → один сброс → птицы с разрывом → бабушка → кот |

Детальные результаты, запасы прыжков и ограничения — в [LEVEL_AUDIT.md](LEVEL_AUDIT.md).

## Портретная камера

Основная [ссылка игры](https://pavelmartynovlive-bit.github.io/something-app/) теперь открывает портретный вид C. Масштаб постоянен; физика и размеры объектов не менялись. На компьютере используется узкая портретная рамка, на телефоне — вертикальная ориентация. Manifest PWA также портретный.

Старые переключатели A/B/C оставлены для сравнения кадра: A/B горизонтальные, C портретный; переключение начинает новый забег. [CAMERA_COMPARISON.md](CAMERA_COMPARISON.md) хранит **исторические** измерения предыдущего уровня и не описывает новую постановку самоката.

Проверка HUD и поворота: `npm run test:presentation` при работающем dev-сервере.

## Проверка уровня

Полный аудит по секциям, измерения, clean-run flow и ограничения проверки: [LEVEL_AUDIT.md](LEVEL_AUDIT.md).

Чистые маршруты: 41,55с без ударов и лавочки. Ноль на старте с восстановлением: 64,37с; намеренные ошибки: 44,45с. Самый длинный интервал без зарегистрированного ввода/видимого выбора — 3,58с в чистом забеге, 5,92с при старте с нулём. Автосбор корма не считается действием. Дополнительный диагностический прогон с постоянно принудительным нулём также достигает кота без столкновений.

Для повторяемой проверки нужен dev-сервер Vite и Chromium:

```sh
npx playwright install chromium
npm run dev
```

В другом терминале:

```sh
npm run test:level
npm run build
```

При наличии системного `/usr/bin/chromium` загрузка браузера не нужна. `CHROMIUM_PATH` задаёт другой исполняемый файл, `LEVEL_URL` — адрес dev-сервера (по умолчанию `http://localhost:5173`). Проверки используют настоящую физику Phaser и события ввода; JSON сохраняется во временную папку.

## Ручная проверка на телефоне

Проверь чтение первой развилки до прыжка, различимость светлых навесов и сплошных террас, тап в разных местах, нулевую энергию, пропуск/использование лавочки, безопасное падение, сбор корма и три исхода у кота. Поворот, возврат из другой вкладки, установка PWA и офлайн-запуск также требуют проверки на настоящих Safari/iOS и Chrome/Android. Автоматические результаты Chromium не заменяют оценку ощущений игроком.
