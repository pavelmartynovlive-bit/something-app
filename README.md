# Таня и голодный кот

Одна мобильная сцена auto-runner на Phaser 3 + TypeScript + Vite, без backend, внешнего арта и сохранений. Таня бежит сама; игрок управляет только прыжками. Прохождение — примерно 45 секунд, события идут каждые 2–4 секунды на обычной скорости.

Нужен Node.js 22.12+ (или 20.19+).

```sh
npm ci
npm run dev
```

Открой адрес Vite. Для телефона в одной сети используй сетевой адрес компьютера и порт 5173. Играй горизонтально.

```sh
npm run build
npm run preview
```

Production-файлы — в `dist/`. Размещай **всю папку** на статическом HTTPS-хостинге. Manifest, PNG-иконки и service worker включены в сборку. Относительные пути поддерживают размещение в подпапке, например на GitHub Pages.

## Установка на телефон

1. Опубликуй `dist/` и открой HTTPS-ссылку на телефоне. Адрес компьютера вида `http://192.168…` подходит для разработки, но не для полноценного PWA с офлайн-режимом.
2. Android: открой в Chrome и нажми «Установить» в игре, либо меню ⋮ → «Установить приложение» / «Добавить на главный экран».
3. iPhone: открой в Safari → «Поделиться» → «На экран Домой» → «Добавить». Системное окно установки на iOS нельзя открыть программно: кнопка игры показывает эти шаги.
4. Запускай с иконки. Играй горизонтально; iOS может потребовать повернуть телефон вручную.

Для первой загрузки нужен интернет. В окне «Установить» дождись сообщения «Игра сохранена», затем можно проверить запуск в авиарежиме. Сохранения прогресса по-прежнему нет: каждый новый запуск начинает сцену заново. При новой публикации закрой все окна установленной игры и открой снова, чтобы применить обновление; текущий забег не перезагружается автоматически.

Варианты публикации:

| Вариант | Как разместить |
| --- | --- |
| Netlify — проще всего для первой проверки | Собери `npm run build`, загрузи папку `dist` через ручной deploy в Netlify. Получишь HTTPS-ссылку. |
| Vercel — автоматические обновления из GitHub | Подключи репозиторий, build command `npm run build`, output directory `dist`. |
| GitHub Pages — всё рядом с репозиторием | Публикуй содержимое `dist` через GitHub Actions; в настройках Pages выбери источник GitHub Actions. |

Сборка создаёт `dist/sw.js` со списком всех файлов и версией кеша. В `npm run dev` service worker не включается. Для локальной проверки PWA используй `npm run build` и `npm run preview` на localhost; для телефона нужна HTTPS-ссылка. Хостинг и HTTPS-ссылка ещё не настроены.

### GitHub Pages для этого репозитория

Workflow `.github/workflows/pages.yml` собирает игру при каждом push в `main` и публикует `dist/` через GitHub Actions.

1. В репозитории открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. Открой **Actions → Publish game to GitHub Pages → Run workflow**, выбери `main` и запусти. Последующие изменения в `main` публикуются автоматически.
3. После успешного job `deploy` ссылка на сайт будет в **Settings → Pages** и в deployment `github-pages`.

Ожидаемый адрес для этого репозитория: `https://pavelmartynovlive-bit.github.io/something-app/`. Он станет доступен только после успешной публикации. Если Pages недоступен для приватного репозитория на текущем тарифе, GitHub покажет ограничение в Settings → Pages; не меняй видимость репозитория без отдельного решения.

## Управление и механика

- Таня автоматически бежит вправо со скоростью 330px/s. Управления направлением и стика нет.
- На телефоне тапни в любом месте игровой области; на компьютере Space / ↑ — прыжок.
- Прыжок не расходует энергию. Предусмотрены coyote time 130ms и jump buffer 150ms.
- Обычный бег не расходует энергию. Удар об препятствие или бабку снимает 15; cooldown 1,4 секунды защищает от повторного урона при одном контакте. Бег не останавливается и не меняет направление.
- Lipton восстанавливает 30 энергии, максимум — 100.
- При нуле скорость снижается до 130px/s на 4 секунды, после чего возвращаются 30 энергии и обычная скорость. Прыжки доступны и в замедлении. Подбор Lipton восстанавливает скорость сразу.
- Падение возвращает на последний безопасный checkpoint без перезапуска и без повторного появления собранных бутылок; автоматический бег продолжается.
- Подойди к коту: Таня покормит его автоматически. На финальном экране можно начать заново.

Все параметры и раскладка уровня — в `src/settings.ts`. Сцена — `src/main.ts`, обработка тапа — `src/controls.ts`.

## Что проверено

Production-сборка и TypeScript проходят. В Chromium через Playwright проверены автоматический бег, отсутствие влияния A / ←, бесплатный прыжок Space / ↑, реальные touch-события слева, по центру и справа, урон от препятствий и бабок с cooldown без блокировки движения, Lipton и ограничение энергии 100, замедление при нуле с сохранением прыжка и автоматическим восстановлением. Проверены прыжок после схода с края (coyote time) и input перед приземлением (jump buffer). Полный автоматизированный забег через игровую физику без телепортов прошёл за 45 секунд: все бутылки собраны, кот накормлен, повторный автоматический забег работает. Это проверка механики, а не оценка того, насколько игра весёлая.

Для PWA проверены manifest и отсутствие ошибок устанавливаемости в обычном профиле Chromium, кеширование всех файлов сборки, перезагрузка и игра с отключённой сетью, работа из корня сайта и подпапки `/tanya/`. Инструкция для iPhone проверена с его user agent, а установка на настоящем iPhone/Android ещё не проверена.

## Ручная проверка на телефоне

Проверь прыжки тапом в разных местах игровой области, поворот экрана, возврат из другой вкладки, отсутствие скролла и zoom, падение в яму, замедление и восстановление при нуле энергии, повторный запуск после кормления кота. Настоящие Safari/iOS и Chrome/Android требуют проверки на устройствах.
